# OpenNotchi website

Landing page for OpenNotchi: React + Vite + TypeScript, Tailwind CSS v4,
shadcn/ui and Motion. The latest version, download links, star count and
contributors are read live from the GitHub API.

From the repo root: `make web` (dev server) or `make web-build`. Or here:

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Icons and the social card in `public/` are generated by `make brand`; don't
edit them by hand.

Deployed on Vercel with **Root Directory** set to `apps/website`. Vercel detects
Vite automatically; `vercel.json` adds `/download` and `/github` redirects.
Pushing to `main` deploys automatically. For a manual deploy, run `npx vercel --prod`
from the **repo root** (running it here fails because Vercel appends the Root
Directory again).
